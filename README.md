# PortScope

A responsive, static port-scanner interface ready to deploy to Netlify.

## Deploy

Drag this folder into Netlify Drop, or import the repository in Netlify. The publish directory is the project root.

## Important

This is an educational browser-only UI, so its results are deliberately simulated: browsers cannot make arbitrary TCP socket connections. For live scans, use an authenticated backend limited to systems you own or are authorized to test.
